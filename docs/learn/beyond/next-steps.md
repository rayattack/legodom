# Where to go next

That is the core of LegoDOM. You can define blocks, give them state, react to input, compose them and keep their data. The project on the right is a small task list that uses most of what you have learned. It is yours to take apart.

Some ideas to try in it:

- Add a filter that hides finished tasks, using a getter.
- Show the count of open tasks in the heading.
- Store the list with `$db` so it survives a reload.

## Keep going

- [Quickstart](/quickstart/) builds a multi-page task tracker in a real project, with routing.
- [Routing](/tutorial/routing) covers URLs, outlets and swapping one region of the page at a time.
- [Server-side rendering](/tutorial/ssr) renders the same blocks to HTML on the server and hydrates them in the browser.
- [The playground](/play/) is this editor with no lesson attached, and a link you can share.

Start a project of your own with:

```bash
npm create legodom@latest my-app
```
